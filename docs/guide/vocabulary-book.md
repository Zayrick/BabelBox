# 单词本 Beta

单词本把“阅读时查到一个词”延伸成一个本地学习闭环：收藏当前单词，稍后主动回忆，并记录它从新词、学习中、熟悉到已掌握的变化。

## 开启与收藏

1. 打开完整设置，进入“单词本 Beta”。
2. 阅读本地存储说明并开启 Beta。
3. 在网页中划选一个英文单词。单词学习卡标题栏会在复制按钮前显示星标。
4. 等译文或词典释义出现后点击星标。实心星表示这个词已经在单词本中；再次点击会更新当前阅读上下文，不会直接删除学习记录。

当前 Beta 只接受单个英文单词：可以包含内部连字符或撇号，但不支持短语、数字、网址或其他语言。大小写、首尾空格和弯撇号会归为同一个词，不会自动把 `run` 与 `running` 合并。

收藏会直接复用卡片中已经取得的译文、音标和词性，不会为了写入单词本再发起一次翻译或词典请求。词典服务暂时不可用但普通译文可用时，仍可保存最小词条。

## 复习与掌握状态

设置页会显示今日待复习、学习中、熟悉和已掌握数量。开始复习后先回忆单词或挖空的阅读上下文，再显示答案，并选择：

- **忘了：** 回到学习中，约 10 分钟后再次到期。
- **记得：** 按 1、3、7、14、30 天逐步延长间隔；连续记得后进入“已掌握”。

这是一套便于理解的 Beta 启发式，不代表经过验证的最佳记忆算法。每次评分都会保留精简复习日志。已掌握的词仍会低频到期；也可以在列表中手动标记已掌握或重新学习。

键盘复习支持：空格显示答案，`1` 选择“忘了”，`2` 选择“记得”，`Esc` 退出本轮。

## 本地数据与隐私

词条与复习日志保存在扩展自己的 IndexedDB 中，不同步、不建账号、不上传复习记录，也不会被“清除翻译缓存”删除。关闭 Beta 只隐藏收藏入口，不会删除已有词条。

只有在主动点击星标时，扩展才会保存最多约 500 个字符的纯文本阅读上下文、页面标题和来源地址；来源地址会移除查询参数与片段，不保存 DOM、Cookie 或整页正文。无痕/隐私窗口中不提供持久收藏入口。

学习数据与普通配置分开管理：

- BabelBox JSON 用于完整备份与合并恢复，包含复习状态和日志。
- Anki TSV 用于导入其他闪卡工具。
- 导出默认不包含上下文和来源；只有主动勾选后才会带出这些可能包含浏览隐私的字段。

浏览器卸载扩展或清除站点/扩展数据时，本地单词本可能一并移除。更换浏览器或卸载前请先导出备份。
