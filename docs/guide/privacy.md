# 数据与隐私

BabelBox 浏览器扩展没有账号体系，也不会把使用记录、网页内容或 API 凭据发送到 BabelBox 自有服务器。翻译、词典和朗读功能仍可能调用你选择的第三方服务；是否出站取决于具体功能和服务配置。

## 哪些数据会离开浏览器

| 功能 | 可能发送的数据 | 接收方 |
| --- | --- | --- |
| 页面、划词和视频字幕翻译 | 待翻译文本、源语言、目标语言、模型和提示词；DeepL 等支持上下文的服务还会收到页面标题或调用上下文 | 当前选择的翻译服务或自定义端点 |
| 输入框翻译 | 输入框中的待翻译文本、源语言和目标语言 | Microsoft 翻译接口；此功能不跟随当前选择的翻译服务 |
| AI 上下文 | 首次生成摘要时发送页面标题、描述和最多 4,000 字符的可读正文；翻译时发送该摘要、截断后的部分原始页面上下文和当前待翻译文本 | 当前 AI 翻译服务；此功能默认关闭 |
| 英文单词卡 | 被选中的单词会发送给公共词典服务；词典返回的释义和例句会发送给当前翻译服务生成译文 | 公共词典服务和当前翻译服务；不附带页面地址和正文上下文 |
| 划词朗读 | 需要朗读的文本与语言 | Microsoft Edge TTS；失败时可能回退到 Google TTS |
| 图片与圈选翻译 | OCR 识别出的文字 | 当前翻译服务 |
| 独立 userscript 的自动语言检测 | 待判断的文本片段 | 百度翻译语言检测接口；文本放在 POST 请求体中，不放入 URL |

图片 OCR 在扩展的 Offscreen 文档中本地执行。远程图片在需要识别时由扩展后台重新获取，请求不携带网页 Cookie；原图不会作为翻译请求直接发给所选文本翻译服务。圈选截图只在本次处理的内存中使用。

自定义接口、代理和本地服务由用户自行配置。使用非回环的 `http://` 地址时，文本和鉴权信息没有 TLS 传输保护；处理敏感内容时应使用可信的 `https://` 端点或本地回环地址，并核对服务方的数据保留政策。

BabelBox 在服务支持时优先使用请求头传递凭据，例如 Gemini 直连使用 `x-goog-api-key`。少数兼容接口把令牌定义为 URL 的一部分：DeepLX 的 Token 模板由用户明确选择；独立 userscript 的文心一言接口按服务协议把临时访问令牌放入查询参数。这类 URL 可能被网络诊断工具记录，使用时应避免共享完整请求地址。

## 浏览器内保存的数据

- 设置和 API Key、Secret 等凭据一起保存在扩展私有的 `storage.local`，不会写入当前网页的 `localStorage`；凭据按翻译服务实例隔离。
- 最近 10 次配置修改和最近 10 份定时备份保存在扩展私有存储中；定时备份每 6 小时建立一份。配置快照不包含 API 凭据，恢复时保留当前翻译计数和凭据。导出的 JSON 包含 API 凭据，导入时会整体替换当前配置；分享导出文件前请删除其中的 `serviceCredentials`。
- 翻译缓存位于扩展后台的私有 IndexedDB；缓存键为不透明摘要。译文，以及启用 AI 上下文时生成的摘要和截断原始页面上下文，最多保留 24 小时，并受 2,000 条、5 MB 总量限制。可在弹窗中随时清空。
- 发布构建会移除 BabelBox 自有代码的控制台日志；开发源码也不应记录原文、译文、完整请求体、响应体或凭据。

扩展私有存储不对凭据额外加密，不能抵御已经控制扩展代码、浏览器进程或当前系统账户的攻击者。共享或受控设备上请为服务密钥设置最小权限和额度，用完后在设置页删除。

独立 userscript 使用脚本管理器的 `GM_*` 私有存储保存配置和服务凭据，并在当前网站的 IndexedDB 中保存最长 24 小时的翻译缓存。

## 用户可以怎样控制

1. 选择本地 Ollama 或浏览器内置翻译，减少文本出站。
2. 保持 AI 上下文关闭，避免发送额外的可读正文；普通翻译仍可能发送页面标题等调用上下文，详见上表。
3. 在共享设备上使用完毕后，删除对应翻译服务或清空其 API Key。
4. 在弹窗中清空翻译缓存；撤销疑似泄露的 API Key，并在服务商控制台重新生成。
5. 提交 Issue 前删除 API Key、Cookie、个人信息和受保护的原文。
