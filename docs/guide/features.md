# 功能总览

FluentRead 的功能可以拆成三层：在页面中阅读、在局部内容中阅读，以及按自己的服务和习惯进行配置。

## 页面翻译

使用“翻译页面”处理当前网页，译文会作为独立的双语内容插入原文附近。原文仍然存在，因此你可以对照阅读，也可以随时恢复。

<img class="doc-screenshot" src="/screenshots/translation.png" alt="Bilingual page translation" />

适合：新闻、博客、技术文章、在线文档和长篇资料。

## 文档翻译

这是流畅阅读的 Beta 功能。在弹窗的“视频字幕”卡片下方点击“文档翻译”，即可打开独立的文档翻译页。选择或拖入一个本地文件后，FluentRead 会按文件结构提取可翻译片段，并以“原文段落 + 下方译文”的阅读流展示结果；译文可以在下载前直接编辑。

文档页使用独立的翻译服务选择，不会改写网页翻译或视频字幕的服务选择。AI 模型由所选服务实例绑定；如需在同一供应商的多个模型间切换，可以先在“翻译服务”中分别添加实例，再在文档页选择对应名称。

当前支持 PDF、ePub、HTML、JSON、TXT、DOCX、Markdown，以及 SRT、VTT、ASS、SSA、LRC 等字幕文件。系统会根据扩展名和文件签名选择对应解析器：PDF 按页提取文本层，ePub 按 OPF spine 保留章节顺序，DOCX 保留 OOXML 包、正文、页眉和页脚；HTML 会保留标签与属性，Markdown 会跳过代码块和链接，字幕会保留时间轴、换行与格式标记，JSON 只翻译字符串值并保持对象结构。翻译完成后可选择导出同格式的双语文件或仅译文文件。

PDF 双语导出会保留每张原始页面，并在其后追加可阅读的译文页；当前 Beta 支持带文本层的 PDF，纯扫描件会提示需要 OCR。文件内容在浏览器本地解析，只有提取出的待翻译文字会发送给用户所选的翻译服务。

文件默认只在当前浏览器页面中读取和重组；实际翻译内容会按照你在“翻译服务”中选择的服务发送。仓库中的 `examples/document-translation/` 提供了每种格式的可直接打开样例和二进制样例生成脚本。

### 始终翻译常用网站

在扩展弹窗中可以为当前网站开启“始终翻译”。开启后，再访问这个网站时会自动开始全文翻译；手动恢复原文只影响当前页面，刷新或重新打开网站后仍会按规则自动翻译。

站点规则按主域名匹配并覆盖它的所有子域名。例如，在 `docs.example.com` 开启后会保存为 `example.com`，随后访问 `news.example.com` 也会自动翻译。`bbc.co.uk`、独立托管的 `name.github.io` 等地址会根据公共后缀规则正确区分，不会简单截取网址最后两段。

在完整设置的“网站自动翻译”页面中，可以查看、添加和删除站点规则，也可以选择让所有网站自动翻译。输入支持完整网址或域名，并会在保存前统一转换为实际生效的主域名；浏览器内部页和本地文件页不支持网页翻译与站点规则，弹窗会保留当前页面信息并明确提示不可用。

如果某个网站不希望出现任何 FluentRead 功能，可以在弹窗中点击“在此网站禁用扩展”。该规则同样按主域名保存，并覆盖所有子域名；禁用规则优先于全局自动翻译和“始终翻译”规则。完整设置的“网站规则”页面可以查看、添加和删除禁用名单。

## 选区翻译与悬浮翻译

不需要整页翻译时，直接选中句子、段落或术语即可。选区翻译更适合快速查词、核对句意和处理页面中的少量外语内容。

可用的触发方式、快捷键和显示行为会受到当前浏览器及页面结构影响；遇到页面不响应时，优先尝试手动选择文本或使用弹窗按钮。设置页的“交互与快捷键”中可以调整“悬浮翻译延迟”（默认 50ms）；如果 `Ctrl+C` 等组合键容易误触翻译，可以适当调高等待时间。

在弹窗的“划词翻译”卡片中还可以单独开启“圈选翻译”。开启后按住 `Shift + Z` 拖拽页面区域，适合翻译图片、视频画面、漫画气泡或无法直接选中的文字；释放鼠标后，FluentRead 会通过后台截图和 Offscreen OCR 处理当前可见区域，并把结果覆盖在原区域上。截图只在本次识别期间保存在内存中，不会写入磁盘；按 `Esc` 或结果右上角的关闭按钮即可移除覆盖层。首次使用图片识别时，需要先在图片翻译设置中下载对应的 OCR 语言包。

划词翻译结果旁的扬声器按钮提供免费 Edge TTS 朗读。默认会按当前语言依次尝试多个音色；也可以在同一张“划词翻译”设置卡片中选择多个语言音色，按选择顺序作为回退链。播放由扩展自己的 Offscreen 文档承接，页面有严格媒体 CSP 时仍可继续朗读；Edge TTS 全部不可用时，再回退到浏览器语音和 Google TTS。

选中一个英文单词时，划词卡片会切换为学习模式：显示单词、音标、可播放的词典发音、词性、英文释义、例句和当前目标语言译文。词典只发送被选中的单词，不发送页面地址或上下文；结果来自多个公开/免费数据源，并在扩展后台按顺序降级。外部服务不可用时，仍会保留普通划词翻译和 Edge TTS / 浏览器语音回退。

开启[单词本 Beta](/guide/vocabulary-book) 后，单词学习卡标题栏会显示收藏星标。点击会把当前译文、音标和受限的阅读上下文保存到本地单词本，之后可以在完整设置中搜索、复习、跟踪掌握程度并独立导出学习数据；收藏本身不会增加一次翻译或词典请求。

## 图片翻译

对截图、漫画、扫描资料和图片中的文字进行识别，再请求已配置的翻译服务。图片翻译通常比普通文本需要更多处理时间，准确率也会受到字体、清晰度、背景和语言影响。

详细流程见[图片翻译](/guide/image-translation)。

## 多种翻译服务

FluentRead 将翻译服务作为可替换的适配器。你可以按场景选择：

| 类型 | 适合场景 | 需要注意 |
| --- | --- | --- |
| 免费服务 | 低门槛体验、临时阅读 | 可用性和速度取决于公共服务状态 |
| Microsoft、Google、DeepL | 稳定的云端翻译 | 需要自行准备凭据，并遵守服务条款 |
| OpenAI 兼容 API | 希望使用大模型理解上下文 | 成本、延迟和输出稳定性取决于模型 |
| Ollama | 希望在本机处理内容 | 需要本地模型、足够的硬件和正确的 CORS 配置 |

新安装默认提供机器翻译服务。AI 服务需要在“翻译服务”页点击搜索栏右侧的“+”，先从列表中选择供应商，再到新增服务的详情中配置模型和凭据；同一供应商可以保留多个模型实例。只有已启用的服务会出现在各功能的选择菜单与翻译中心中。配置方法请看[翻译服务](/config/translation-engines)。

## 可恢复、可重译

翻译结果不会永久覆盖原文。你可以恢复当前页面，再修改服务、语言或样式后重新翻译。对于长页面，建议先用小段落验证服务配置，再开始整页处理。

### YouTube 视频字幕翻译（Beta 测试）
视频字幕翻译默认关闭。在 YouTube 播放器右侧控制栏会显示 FluentRead 图标入口，播放器菜单顶部显示中文品牌“流畅阅读”；点击后可查看“开启字幕翻译”的勾选状态、当前视频翻译服务和视频设置入口。开启后，FluentRead 会通过双语字幕面板显示译文和原文：原生字幕可见时面板会避开原生字幕并显示在其上方，逐词合并为整段原文时则固定在播放器底部安全区上方；面板带半透明深色背景、柔和阴影，不会因 YouTube 原字幕重绘或逐词宽度变化而上下跳动。

播放器菜单还支持“双语 / 仅译文 / 仅原文”三种显示模式、独立的“显示字幕”开关，以及“下载原文字幕”和“下载译文字幕”两个操作。下载会优先使用 YouTube 的 timedtext 字幕事件生成带时间轴的 `.srt` 文件；原文轨道读取期间会显示加载状态，慢于 2 秒时继续提示仍在读取，成功后显示实际字幕条数。译文下载会复用已经翻译的字幕，并用当前视频翻译服务补齐其余内容，在菜单中显示逐条进度。长视频可能需要更多时间和对应服务额度；任一段翻译失败时不会生成冒充完整译文的残缺文件。如果视频没有打开原生字幕或 YouTube 没有返回完整轨道，菜单会提示开启字幕或重试，而不会把当前屏幕的一行字幕冒充完整文件。它不上传音频，也不改变播放器时间轴；如果视频没有打开原生字幕，翻译入口仍会显示，但不会凭空生成字幕。

视频翻译服务与网页文本翻译服务独立配置：可以在“通用设置”或弹窗的“视频字幕 Beta 测试”卡片中单独选择机器翻译或 AI 服务，并调整 FluentRead 字幕字号。视频默认使用微软翻译，也可以切换到 DeepLX、OpenAI、Gemini 等服务；机器翻译会提前约 10 秒预取，AI 服务会提前约 30 秒预取。原生字幕逐词写入时，FluentRead 会先按 timedtext 时间轴合并连续短词 cue，再复用完整 cue 的一次翻译，并在播放器中用整段原文覆盖逐词 DOM，避免长句一直等不到停顿；播放器时间轴进入下一条 cue 后，即使 YouTube 原生字幕 DOM 暂时落后，也会优先显示当前 cue。字幕面板紧贴原文和译文，仅保留少量内边距。站点一次性给出完整句时直接显示整句。若尚未拿到完整时间轴则回退到字幕出现后的实时翻译。完整设置中的“视频字幕 Beta 测试”页面可以关闭该功能；当前版本仅处理 YouTube 的 `/watch` 和 `/shorts` 页面。

## 阅读样式与主题

设置页提供主题、译文样式、字号和相关显示选项。建议先从默认样式开始，再根据网页背景选择浅色、深色或更低对比度的方案。

## 缓存与服务管理

启用缓存后，重复请求相同内容时可以减少等待和服务调用。缓存并不等同于永久存档；如果页面内容发生变化，建议恢复原文后重新翻译。

## 快捷键

常用操作可以绑定浏览器快捷键，包括翻译页面、恢复原文、翻译选区等。不同浏览器对扩展快捷键的管理方式不同，具体配置步骤见[自定义快捷键](/guide/custom-hotkey)。
