# 设置总览

打开 BabelBox 弹窗，点击设置图标即可进入选项页。设置会保存在当前浏览器的扩展存储中，不需要登录账号。

## 常用设置

### 语言

- **源语言**：网页原文的语言。可以选择具体语言，也可以交给服务自动识别。
- **目标语言**：译文语言。阅读中途修改后，恢复原文再重新翻译更稳妥。

### 翻译模式

根据页面和阅读习惯选择页面翻译、选区翻译或其他可用模式。长文建议先用选区确认服务正常，再执行整页翻译。

### 翻译样式

调整译文的颜色、背景、字号和显示方式。样式会尽量隔离在 BabelBox 的内容节点内，不主动改写网站原有 CSS。

### 主题与界面

可以使用浅色、深色或跟随系统。弹窗、设置页、文档翻译页、userscript 设置面板以及 BabelBox 在网页内显示的浮层会使用同一主题；文件正文与 PDF 纸张预览保留原始页面底色。

### 动画效果

高级选项中的“动画效果”使用下拉菜单选择。“旋转”会在待翻译文字右侧显示旋转加载图标；“文字流光”会通过透明度蒙版让正在翻译的原文显示扫光效果，并保留网页原有文字颜色；“静态”会停止运动并保留静态状态提示。

### 翻译并发

“翻译并发数”控制当前页面或扩展界面同时发往翻译后台的任务数量，默认值为 6，最小值为 1，界面不设置预置上界。全文翻译和文档逐段翻译统一使用该翻译队列，不叠加功能级固定并发上限。不同标签页拥有各自的队列；较高的数值可能更快触发服务商的频率限制、增加费用并占用更多浏览器资源，应根据所用服务的配额和设备能力设置。

### 网站规则

弹窗中的“始终翻译当前网站”会把当前网站的主域名加入自动翻译名单，并覆盖同一主域名下的所有子域名；“在此网站禁用扩展”会把主域名加入禁用名单，使该网站及其子域不显示或触发 BabelBox 功能。禁用规则优先于自动翻译规则。完整设置的“网站规则”页面可以添加完整网址或域名、删除已有规则，或开启所有网站自动翻译。站点名单保存在浏览器扩展配置中，也会包含在配置导入、导出和历史恢复中。

同一页面还提供“内容过滤”。全局配置可以决定是否跳过隐藏内容和可编辑内容，并使用 CSS 选择器添加“不翻译”或“强制翻译”规则；弹窗中的“内容过滤规则”可直接为当前网站添加覆盖规则。规则从上到下匹配，第一条命中的规则生效；可以拖动手柄排序，也可以聚焦手柄后使用 `Alt + ↑/↓` 调整。网站规则按主域名及其所有子域生效，并优先于同一元素命中的全局规则。若父级已经被排除，子级的“强制翻译”不会重新打开整个父级区域。

脚本、表单、代码、网页声明不翻译、数学公式以及 GitHub、X、Reddit、YouTube、Discord 等网站的适配选择器都以默认配置提供，可以编辑或删除；“恢复默认”会重新载入当前版本的内置默认值。无效的 CSS 选择器不会中断网页扫描。内容过滤会随配置导入、导出、历史恢复和定时备份一起保存。

### 配置管理

配置管理保留最近 10 次修改，并由扩展后台每 6 小时建立一份定时备份，定时备份最多保留 10 份。两类快照都可以在设置页恢复；恢复配置时保留当前翻译计数、API 凭据和凭据持久化选择。

## 服务设置

翻译服务单独放在服务管理页。新安装默认只有机器翻译服务；AI 服务通过搜索栏右侧的“+”从供应商列表直接添加，新增实例的模型 ID 初始为空，再在服务详情中完成配置。同一供应商可以添加多个独立实例。每个服务通常包含：

- 自定义名称、供应商图标和请求地址；
- API 密钥、模型 ID 或其他凭据；
- 可选的超时、并发或高级参数；
- 当前配置是否完整的状态提示；
- 位于每项右侧的启用开关。

AI 服务名称初始使用供应商名称，也可以自行修改。支持模型列表 API 的供应商会动态加载可选模型，并始终允许手动输入；其他供应商只提供模型 ID 输入框。关闭开关会保留该实例的配置，但它不会出现在使用服务的下拉菜单或翻译中心中。自行添加的 AI 实例可以删除，删除时会同时清除该实例的本地凭据；内置机器翻译项不可删除，只能启用或停用。

不要把 API 密钥写入公开 Issue、截图或仓库。服务的计费、配额、地区限制和数据保留策略由服务提供方决定。

## 翻译中心

翻译中心可以把同一段文字同时交给多个已启用服务，方便比较结果。结果卡片可通过左侧手柄拖动排序，拖动时会实时让出位置；也可以聚焦手柄后使用 `Alt + ↑/↓` 调整。已选服务、卡片顺序和翻译中心使用的源语言、目标语言会保存到扩展配置中。

## 缓存

启用缓存可以减少重复请求。若你正在调试服务、修改提示词或需要获取最新结果，可以暂时关闭缓存，或先恢复原文后再次翻译。

## 快捷键

扩展快捷键由浏览器统一管理。修改后如果没有立即生效，请检查是否与浏览器或其他扩展占用了同一组合键。详细步骤见[自定义快捷键](/guide/custom-hotkey)。
